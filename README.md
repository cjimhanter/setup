# setup

Публичный паспорт моего рабочего и игрового сетапа.

## Цель

- в EuroAion 4.6 и других лёгких / CPU-зависимых играх — максимально полно использовать монитор 1920×1080 165 Гц;
- в тяжёлых играх вроде Baldur’s Gate 3 — комфортный стабильный геймплей без обязательной цели 165–200 FPS;
- сохранить сильную AM5-базу и обновлять RAM / GPU только тогда, когда это оправдано.

## GitHub Pages

Сайт публикуется автоматически через GitHub Actions при каждом push в `main`.

## Структура

- `index.html` — страница;
- `styles.css` — оформление;
- `script.js` — рендер карточек и схемы подключений;
- `data/setup.json` — актуальные данные по комплектующим и периферии;
- `.github/workflows/pages.yml` — публикация через GitHub Pages.

Чтобы обновить модель, цену, статус или подключение, в большинстве случаев достаточно изменить `data/setup.json`.

## Privacy

В публичной версии намеренно не хранятся серийные номера, номера чеков, IP-адреса, учётные данные и другая приватная информация.
